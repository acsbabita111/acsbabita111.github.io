टाइपिंग शुरू करने से पहले

न्यूनतम आवश्यकता

  • Android 8+
  • 2GB RAM
  • OTG Dongle
  • QWERTY Keyboard
  • Internet
  • Landscape Mode only

UI नियम

  • Landscape optimized (max usable height ~400px)
  • बड़े font
  • simple UI
  • fast loading
  • no heavy animation
  • correct → green
  • wrong → red
  • active → orange

Modes

  • Fun Typing — letters, words, sound feedback
  • Practice Mode — drills, weak keys
  • Official Test — system text

Learning Elements

  • finger guide
  • posture training
  • weak key system

Scoring System (Final)

  • Gross WPM = (Total Characters ÷ 5) ÷ Minutes
  • Net WPM = (Correct Characters ÷ 5) ÷ Minutes
  • Accuracy = (Correct ÷ Total) × 100
  • Consistency = हर 30 सेकंड का WPM, standard deviation, normalize करके 0–100
  • Weak Keys = highest error keys, slow keys

Onboarding Flow

  • 1. Splash
  • 2. Rotate screen
  • 3. Connect keyboard
  • 4. Press any key
  • 5. User type select
  • 6. Consent
  • 7. Finger guide
  • 8. First practice
  • 9. Dashboard
