LESSON L095

फाइल नेमिंग (File Naming)

सही File Name भविष्य के काम में क्यों मदद करता है?
Lesson 95 / 150
🎯 आज का लक्ष्य: अपनी डिजिटल फाइलों को व्यवस्थित नाम देकर समय बचाना सीखना।
1. प्रस्तावना

कल्पना कीजिए — आपने 3 महीने पहले एक बहुत अच्छा Video Save किया था — लेकिन उसका नाम रखा था "video1.mp4" या "Untitled।" आज जब वह File चाहिए — तो क्या आप उसे जल्दी ढूँढ पाएंगे? नहीं।

👉 आज हम सीखेंगे कि Files को सही नाम देना क्यों ज़रूरी है — और यह आदत भविष्य में हमारा बहुत समय कैसे बचाती है।

🔴 2. जरुरी Technical Words

पाठ से जुड़े जरुरी Technical Words

  • File Naming: File को सही और आसानी से पहचान में आने वाला नाम देना।
  • Naming Convention: Files का नाम रखने का एक तय और एक जैसा नियम।
  • Workflow: काम को सुचारू और व्यवस्थित तरीके से करना।
  • Version Control: File के पुराने और नए रूप को नाम से पहचानना (जैसे v1 और v2)।
  • Systematic: व्यवस्थित और सोच-समझकर काम करना।
3. Concept

कांसेप्ट (Concept)

जैसे इंसान की पहचान उसके नाम से होती है — वैसे ही File की पहचान उसके नाम से होती है। अगर नाम Untitled, New File, VID1234 या abc हो तो खोजने में बहुत परेशानी होती है।

👉 इसीलिए हमें एक Naming Convention अपनाना चाहिए। जैसे:

  • School_Project_Draft
  • Science_Quiz_v1
  • Village_Documentary_Final

अगर File में बाद में बदलाव हो तो नया Version दें: Script_v1 → Script_v2 → Script_Final।

4. Knowledge Points

Knowledge Points (नॉलेज पॉइंट्स)

🟢 Easy (ईज़ी)

  • 1. "Untitled" या "abc" जैसे नाम भविष्य में परेशानी पैदा करते हैं।
  • 2. नाम रखने के तय नियम को Naming Convention कहते हैं।
  • 3. सही File Naming समय बचाने की एक ज़रूरी डिजिटल आदत है।

🟡 Core (कोर)

  • 1. अच्छे नाम से Search Bar में File जल्दी और आसानी से मिल जाती है।
  • 2. Version Control (v1, v2, Final) से काम के विकास को पहचाना जा सकता है।

🔵 Advanced (एडवांस्ड)

  • 1. नाम में YYYY-MM-DD Format में Date जोड़ने से Files खुद-ब-खुद Sort हो जाती हैं।
  • 2. नाम में Space की जगह Underscore (_) या Dash (-) का उपयोग करना सबसे सुरक्षित है।

7. Behavior Change

👉 नियम: मैं आज के बाद किसी भी File को "Untitled" या बेकार नाम से Save नहीं करूँगा/करूँगी — तुरंत उसे सही और साफ़ नाम दूँगा/दूँगी।

8. Safety & Compatibility

सुरक्षा के लिए ध्यान रखें:

  • Special Characters (जैसे * \ / : ? " < > |) का उपयोग न करें।
  • नाम में कभी भी Password या Phone Number न लिखें।
  • केवल अक्षर, नंबर, Underscore (_) या Dash (-) ही उपयोग करें।
